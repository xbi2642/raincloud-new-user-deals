这是雨云比较实在的一个设计:云服务器和游戏云产品支持**1元试用1天**。

## 关于雨云新用户优惠,常被问到的几个问题

**注册了但没收到5折券?**
先确认微信绑没绑。绑定是发券的触发条件,不是可选项。

**5折券能和年付7折一起用吗?**
这两类折扣的叠加关系在结算页会直接体现,自己推容易推错。券主要作用在首月,所以更稳的做法是先月付体验,确定要长期用再走年付。

**优惠券有效期过了能补吗?**
没有公开的可补发机制,券发出那天就建议尽快用掉。

**免费服务器是不是真的免费?**
积分兑换来的游戏云确实不需要付现金,但要靠签到攒积分续期。积分断了,服务器会过期释放。

**能退款吗?**
7天内、每账号限3次、退到余额。日付产品不在范围内,已经领过消费积分的产品也退不了。
